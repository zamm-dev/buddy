# App

| Path | Purpose |
| --- | --- |
| `lib/main.dart` | App entrypoint (starter counter app) |
| `test/` | Widget tests, run with `flutter test` |
| `android/`, `ios/`, `macos/`, `web/` | Platform runners generated by `flutter create` |
| `pubspec.yaml` | Dependencies and Flutter configuration |
| `analysis_options.yaml` | Lint rules used by `flutter analyze` |
